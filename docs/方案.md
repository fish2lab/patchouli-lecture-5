# 方案：心灵的苦难，有物质的机制（帕秋莉讲座 · 光遗传学）

## 一句话

让 B 站上没有神经科学基础的观众，在约 5 分半钟里记住：精神疾病背后有能被实验拨动的脑回路，今年的诺贝尔生理学或医学奖奖励的，就是用光拨动回路的开关。

## 受众和时长

- 受众：B 站泛科普观众、大学生。
- 时长：约 5 分半，台词 46 条。新概念三个：**见光就开的通道**、**光遗传学：开关装进指定神经元，拨一下看行为变不变**、**三种病是同一套系统在不同层面上失稳**。

## 和前几集的区别

- 舞台换成**教室里的推拉黑板**，照 V8 黑板报的视觉规范抄（`src/lec/chalk.js`）：板岩绿底、白粉笔、黄色只标新出现的东西、粉色标问题、蓝色是光、绿色是恢复；粉笔头写字带粉尘；板擦擦掉的东西有意思；一段的内容可以比一屏宽，镜头在段内平移；结尾一张粉笔思维导图。
- **古明地觉**第一次登场。她能读心，开场一句「我读得出你难过，读不出你为什么难过」把全片的问题抛出来；结尾她说出主张。帕秋莉执粉笔讲机制，琪露诺从右下角冒出来提问。
- 四个等轴测线框图照 hairline（MIT）的样子用粉笔重画（`src/lec/iso.js`），在病那一段当三个主物件，光遗传那一段当「被光点亮的一群神经元」。

## 主线

1. 一种绿藻靠眼点里一个见光就开的离子通道感光；Nagel 和 Hegemann 在 2002–2003 年证明它是被光直接打开的通道。
2. 2005 年它被装进神经元，光一亮神经元就在毫秒内放电；能开关，就能检验因果：拨一下，看行为变不变。
3. 在小鼠身上，早期阿尔茨海默模型的记忆能被光取回，驱动一类抑制性神经元能带起 γ 节律，按节律点亮多巴胺神经元能减轻类抑郁行为；这些证据几乎都来自小鼠，能被理解离能被治愈还有距离。

收尾用主张原句：它们各不相同，却都指向同一个事实——心灵的苦难，有其物质的、可被理解的机制。

## 台词

who：P = patchouli（默认），S = satori，C = cirno。台词不出现拉丁单字母；人名用音译：内格尔（Nagel）、黑格曼（Hegemann）、戴瑟罗斯（Deisseroth）、利根川进。

### 0 opening 开场：读不出的「为什么」（约 40 秒）
1. C（proud）：帕秋莉！今年的诺贝尔奖，是不是发给会读心的人了？
2. P（annoyed）：发给了一把开关。
3. S：会读心的是我。古明地觉，地灵殿的主人。
4. S（sad）：可我只读得出一个人在难过，读不出他为什么难过。
5. P：今天就讲这个为什么。人脑里大约有八百六十亿个神经元。
6. P：记忆、情感，整个精神世界，都靠它们之间的电信号和化学信号传递。

### 1 alga 一颗见光就开的开关（约 45 秒）
1. P：先说一种绿藻。它只有一个细胞，却会朝着光游。
2. C（confused）：它连眼睛都没有吧？
3. P：它有一个眼点。眼点上有一种通道，见光就打开。
4. P：通道一开，带电的离子涌进来，细胞就知道：有光。
5. S：二零零二年前后，内格尔和黑格曼证明了这件事。这个通道叫通道视紫红质。
6. C（surprised）：藻类的开关，跟脑子有什么关系？

### 2 switch 把开关装进神经元（约 55 秒）
1. P：二零零五年，戴瑟罗斯团队把这个通道装进了神经元。
2. P：蓝光一照，神经元就放电；光一灭，它就安静。快到毫秒。
3. S：这套方法叫光遗传学。今年的诺贝尔奖，就发给了它。
4. C（confused）：可是看脑子，不是早就能看了吗？
5. P：以前只能看到，某个脑区和某种行为一起出现，说不清谁导致了谁。
6. P（smug）：现在能拨开关。拨一下，看行为变不变。
7. S：从一起出现，到谁导致谁。

### 3 mice 开灯，关灯（约 50 秒，全片最热闹的一段）
1. C（happy）：那拨一下会怎样？
2. P：点亮下丘脑里八百来个神经元，刚吃饱的小鼠又埋头猛吃。
3. P：点亮另一群，不渴的小鼠跑去喝水。
4. P：再换一处，小鼠会扑向眼前的任何东西，连没有生命的也咬。
5. C（surprised）：开灯就变，关灯就停？
6. P：还能改记忆。给小鼠造一段假的恐惧，它会害怕一个从没吃过苦头的地方。
7. S（smug）：我读心靠第三只眼。他们靠一束光。

### 4 illness 三种失稳（约 75 秒）
1. P：那么，心灵的苦难呢？抑郁、精神分裂、阿尔茨海默病。
2. P：它们是这套系统，在不同层面上的失稳。
3. S：早期阿尔茨海默病模型的小鼠，像是忘了一件事。
4. P：用光重新点亮那段记忆留下的细胞，它又想起来了。
5. S：有的记忆还在，坏掉的是取出它的路。
6. P：精神分裂患者的脑里，一种快节律常常对不齐。
7. P：在小鼠身上驱动一类抑制性神经元，就能把这种节律带起来。
8. S：慢性应激的小鼠，按节律点亮多巴胺神经元，类抑郁的行为就减轻了。
9. C（confused）：那是不是开个灯，病就好了？

### 5 limit 还有一段路（约 35 秒）
1. P（annoyed）：没那么简单。这些结果几乎都来自小鼠。
2. P：光遗传要先改基因，给细胞装上开关，在人脑里很难做到。
3. S：人身上最接近的一次，是一位失明多年的患者，戴上护目镜后，能数出桌上的东西。
4. P：能被理解，离能被治愈，还有一段路。

### 6 ending 物质的、可被理解的（约 45 秒）
1. S：我读得出难过。现在，我也知道它从哪里来了。
2. P：抑郁、精神分裂、阿尔茨海默病，它们各不相同。
3. P：却都指向同一个事实。
4. S（smile）：心灵的苦难，有其物质的、可被理解的机制。
5. C：那我心情不好的时候呢？
6. P（smile）：找人说说，也可以去看医生。简介里有心理援助热线。

## 视觉隐喻

| 段 | 主物件 | 怎么接下一段 |
|---|---|---|
| 0 opening | 一片粉笔点画成的大脑，点与点之间连出闪烁的细线；左上写题目「读不出的为什么」 | 板擦擦掉大脑，只留一个点 → 下一段这个点长成单细胞绿藻 |
| 1 alga | 一个单细胞绿藻（鞭毛摆动，朝右上的蓝色光源游）；镜头推进眼点 → 细胞膜上一个通道，蓝光一到门打开、离子点涌入 | 通道的形状 → 下一段装进神经元的膜上 |
| 2 switch | 一个神经元（胞体 + 树突 + 轴突）膜上镶着通道；蓝光脉冲 → 轴突上跑过放电；镜头右移到 isoTerrain，光纤光点扫过、柱子升起；最后「脑区 ？ 行为」被板擦擦掉「？」改写成箭头 | 箭头 → 下一段的电灯开关拨杆 |
| 3 mice | 一个粉笔画的大电灯开关居中，拨一下切一张小鼠速写（吃、喝、扑咬、发抖），「开灯 / 关灯」两枚印章来回盖；节奏快 | 开关拨杆 → 下一段插头 |
| 4 illness | 一块比一屏宽的黑板分三栏，镜头逐栏走：阿尔茨海默 = isoPlug（插头差一点够到 → 光照后插进去），精神分裂 = isoPatch（线缆乱晃 → 同步摆动），抑郁 = isoPhosphor（点阵熄灭 → 光扫过重新亮）；每栏一个章节徽章和粉笔边 | 镜头退远看三栏全貌 |
| 5 limit | 左「小鼠」右「人」两栏；中间一条粉笔虚线的路，从「可被理解」通往「能被治愈」，只画了一小段 | 路 → 结尾思维导图的一条枝 |
| 6 ending | 主张原句用粗粉笔写在黑板中央、关键词划线；然后切到干净的一侧，一张粉笔思维导图回顾三章 | 片尾 |

## 被否掉的方案

- 直接用 lanshu 的 HyperFrames + MiniMax 管线：和本系列的 Canvas 逐帧引擎、油库里配音、剪纸角色接不上；只抄视觉规范。

- 字幕改成 V8 的「粉笔大标题」：B 站观众习惯底部字幕，保留系列的纸条字幕；黑板上只写正在念的关键词。
- 鬼畜实验里的交配实验：和本集主张无关，不放。
- 「植入快乐的虚假记忆」「小鼠对着光舔」：核对后是错的（见 `docs/来源.md`）。
