## 接口

- 舞台：`ckRoom(c, tau)` 先画；粉笔内容全部在 `ckLayer(c, cam, lc => {...})` 里画（板坐标，cam 缺省时板坐标 = 屏幕坐标）。镜头 `ckCam(tau, [[tau, x, y, z], ...])`，z ≤ 1.06。
- 粉笔：`ckText` `ckWrite`（逐字写出，返回笔尖 head）`ckLine` `ckShape`（hatch 斜线阴影）`ckArrow` `ckRing` `ckUnderline` `ckBorder` `ckBadge` `ckErase`。粉笔头 `ckStick(c, ckToScreen(cam, head), tau)` + `ckDust`。颜色键：ink 白、muted 旧粉笔、yellow 只标新东西、blue 光和结构、pink 问题、green 恢复、orange。字号 ≥ 30。
- 人物：`ogPch(c, tau, L, o)`、`ogSat(c, tau, L, o)`（古明地觉，额外参数 read、eye3、eyeLook）、`ogCirno(c, tau, L, LINES)`（她的台词前自动从右下角冒出、说完缩回）。站位 `OG`。
- 内容区：x 500–1400，y 70–860；琪露诺说话时 x > 1220 且 y > 540 不放东西。人物不和粉笔内容重叠。
- 段末：在 ckLayer 里最后调用 `const e = ogOutro(lc, tau, DUR, cam)`，layer 外 `ogEraser(c, cam, e)`；最后 0.25 秒是干净黑板。段首 0.6 秒内黑板是空的。
- 台词以 `docs/方案.md` 为准，一字不改；用 `seq()` 排，`who: 'satori'` / `'cirno'`。顶层名字带段前缀（S1/s1 …）。
- Playwright 自带浏览器缺失时，设 `CHROMIUM=<Chrome for Testing 可执行文件路径>`。worktree 里先 `npm install`，字体从主仓库 `fonts/` 复制。

## 验收

每段：`node tools/frames.mjs --scene 段名 --grid 24` 退出码 0、无页面报错。衔接和观感由主会话合并后统一看。
全片：`npm run voice && npm run render`。
